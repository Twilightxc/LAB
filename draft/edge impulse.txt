รายละเอียดเนื้อหาทางเทคนิคของ Edge Impulse ที่ใช้สอนในคาบ

----------------------------------------------------------------------
1. Impulse Design & Processing Blocks (DSP)
----------------------------------------------------------------------

  Data Input & Windowing:
    การตัดแบ่งหน้าต่างข้อมูล Time-series เช่น
    กำหนด Window Size 2000 ms และ Window Increase 1000 ms
    เพื่อสร้างข้อมูลสำหรับ Feature Extraction

  DSP Preprocessing:
    ชี้ให้เห็นประโยชน์ของการใช้บล็อก DSP สกัดคุณลักษณะ เช่น
    Spectral Analysis (FFT / Filter) เพื่อลดขนาดข้อมูลก่อนส่งให้ Neural Network
    แทนการส่งข้อมูลดิบทั้งหมดเข้าไป

  Feature Explorer:
    การวิเคราะห์ความสามารถในการแยกแยะข้อมูล
    ผ่านการกระจายตัวของกลุ่มข้อมูลแบบ Visual Explorer


----------------------------------------------------------------------
2. Learning Block & EON Compiler Optimization
----------------------------------------------------------------------

  Model Selection:
    การเลือกใช้ Classification ร่วมกับ Anomaly Detection (K-Means Clustering)
    เพื่อตรวจจับพฤติกรรมผิดปกติที่ไม่เคยปรากฏในชุดข้อมูลฝึกสอน

  EON Tuner:
    การอ่านค่าเปรียบเทียบระหว่างความแม่นยำ (Accuracy)
    กับทรัพยากรที่ใช้บนไมโครคอนโทรลเลอร์ (RAM, Flash ROM และ Inference Latency)
    เพื่อเลือกสเปกที่ลงตัวที่สุด

  EON Compiler Mechanics:
    อธิบายว่า Edge Impulse แปลงโครงข่ายประสาทเทียมออกมาเป็นซอร์สโค้ด C++ โดยตรงอย่างไร
    ซึ่งช่วยตัด Interpreter Overhead ของ TensorFlow Lite Micro ออกไป
    ทำให้ประหยัด RAM ได้สูงสุด ~70% และลด Flash ROM ลงอย่างมาก


----------------------------------------------------------------------
3. Embedded Integration (PlatformIO / C++)
----------------------------------------------------------------------

  Inference API Flow — โครงสร้างการเรียกใช้ในลูปเฟิร์มแวร์:

    #include <your_project_inferencing.h>

    // 1. แปลงข้อมูลเซ็นเซอร์เข้า signal structure
    signal_t signal;
    signal.total_length = EI_CLASSIFIER_DSP_INPUT_FRAME_SIZE;
    signal.get_data = &raw_feature_get_data;

    // 2. สั่งรัน Inference ภายในตัวบอร์ด
    ei_impulse_result_t result = { 0 };
    EI_IMPULSE_ERROR r = run_classifier(&signal, &result, false);

    // 3. ดึงค่าผลลัพธ์
    float anomaly_score = result.anomaly;


  MQTT Telemetry Integration — ส่งผลลัพธ์การอนุมานไปที่ ThingsBoard แทนข้อมูลดิบ:

    {
      "temperature": 29.1,
      "anomaly_score": 0.82,
      "ai_status": "FAULT"
    }


----------------------------------------------------------------------
4. Closed-Loop MLOps & Active Learning
----------------------------------------------------------------------

  • เมื่อโมเดลที่ทำงานบน Edge เกิดข้อผิดพลาดหรือผู้ใช้งานบนแดชบอร์ดพบ False Positive
    ข้อมูลสัญญาณรอบดังกล่าวสามารถถูกส่งกลับไปเก็บใน Dataset
    ผ่าน Ingestion API ของ Edge Impulse

  • กระบวนการนี้ทำให้นักศึกษาเข้าใจบทบาทของ Active Learning
    ในการปรับปรุงโมเดลอย่างต่อเนื่องในสภาพแวดล้อมการใช้งานจริง
