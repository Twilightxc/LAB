AI Loop Engineer
=================

Loop Engineering คือการออกแบบวงรอบการทำงานซ้ำ ๆ


----------------------------------------------------------------------

Loop Engineering คืออะไร? (ไม่ใช่ตัวลูปภายในของเอเจนต์)
----------------------------------------------------------

Loop Engineering ไม่ใช่ตัวลูปของเอเจนต์เอง เพราะเอเจนต์ AI ทุกตัวมีวงรอบภายในของมันอยู่แล้ว
นั่นคือวงจร รับรู้-คิด-ลงมือ-สังเกตผล (Perceive, Reason, Act, Observe) ที่หมุนวนจนกว่าจะถึงเงื่อนไขหยุด

ส่วน Loop Engineering คือการสร้างลูปชั้นนอกที่อยู่เหนือขึ้นไปอีกชั้น เป็นลูปที่ทำงานตามตารางเวลา
คอยป้อนงานให้ตัวเอง เรียกเอเจนต์ผู้ช่วยมาเสริม
และเดินหน้าข้ามวงรอบภายในหลาย ๆ รอบโดยที่คนไม่ต้องนั่งเฝ้าหน้าจอทุกครั้ง

    > จากการสั่งทีละสเต็ป สู่การยิงแล้วลืม


----------------------------------------------------------------------

5 หลักการออกแบบ Loop ที่ดี
---------------------------

  1. ตั้งเป้าหมายให้ลูปอย่างชัดเจน
     และเช็กให้แน่ใจว่า AI เข้าใจเป้าหมายตรงกับเรา

  2. มีกลไกประเมินลูป
     เพื่อให้ AI รู้ว่าเมื่อไรควรวนต่อและเมื่อไรควรหยุด

  3. ใส่จุดเช็กที่ให้มนุษย์เข้ามาแทรกได้
     เพื่อให้ AI คอยรายงานสถานะระหว่างวนลูป และเปิดช่องให้คนแก้ทางหรือสั่งปิดได้ทัน

  4. กำหนดเงื่อนไขหยุดลูปให้ชัด
     ไม่ว่าจะหยุดเพราะถึงเป้าหมายแล้ว หรือหยุดเพราะใช้เวลาและทรัพยากรเกินเพดานที่ตั้งไว้

  5. ต้องทดสอบลูปก่อนปล่อยจริงเสมอ
     ไม่ว่าจะมั่นใจในลูปของตัวเองแค่ไหนก็ตาม ลองให้ AI รันลูปสั้น ๆ สักสองสามรอบ ดูว่าเกิดอะไรขึ้น แล้วค่อยปรับ


----------------------------------------------------------------------

วงจรหลัก (Main Loop)
---------------------

    Goal -> Context -> Action -> Check -> Fix -> Repeat -> Review

สรุปเป็น 3 เฟสย่อ:

    main {
        think       ← ทำความเข้าใจบริบท วางแผน
        build       ← ลงมือทำ
        verify      ← ตรวจสอบผลลัพธ์
    }


----------------------------------------------------------------------

ตัวอย่าง Prompt สำหรับสั่ง AI (Loop Engineering)
-------------------------------------------------

    ผมต้องการให้คุณทำงานแบบ Loop Engineering
    เป้าหมายคือสร้างหน้า Login สำหรับโปรเจคนี้

    ก่อนเริ่มให้คุณทำ 5 ขั้นตอนนี้:

      1. อ่านโครงสร้างโปรเจคก่อน
      2. สรุปสิ่งที่เข้าใจ
      3. วางแผนการทำงานเป็น task ย่อย
      4. ลงมือแก้ทีละ task
      5. หลังแก้เสร็จ ให้บอกวิธีทดสอบ เช่น npm run build, npm test หรือคำสั่งที่เหมาะสม

    กติกา:

      - อย่าแก้หลายเรื่องพร้อมกันเกินไป
      - ถ้าไม่แน่ใจให้ถามก่อน
      - ถ้ามี error ให้ใช้ error message เป็น feedback แล้วแก้ซ้ำ
      - หลังจบงาน ให้สรุปว่าแก้ไฟล์อะไรไปบ้าง
      - ถ้ามีความเสี่ยงด้าน security ให้แจ้ง

----------------------------------------------------------------------

Loop Engineering ไม่ใช่แค่การสั่งให้ AI ทำงานซ้ำ ๆ เท่านั้น
แต่เป็นการออกแบบ “ระบบการทำงาน” ที่ทำให้ AI ทำงานได้ต่อเนื่องด้วยตัวเองมากขึ้น
โดยมีหลักการสำคัญคือการกำหนดวงจรให้ชัดเจน มีการตรวจสอบผลลัพธ์ระหว่างทาง และมีจังหวะให้มนุษย์เข้ามาแทรกได้
เมื่อออกแบบเสร็จแล้ว จะได้เป็นตัวอย่าง Prompt ที่ชัดเจนเพื่อให้ AI เข้าใจวิธีการทำงานของ Loop Engineering ได้ทันที
