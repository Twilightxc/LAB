Edge Impulse คืออะไร?
=======================

**Edge Impulse** คือแพลตฟอร์มการพัฒนาแบบครบวงจร (End-to-End Development Platform) สำหรับ **Edge AI** และ **TinyML**
ที่ออกแบบมาเพื่อช่วยให้นักพัฒนาสามารถสร้าง, เทรน, ปรับแต่งให้เหมาะสม (Optimize) และนำโมเดล Machine Learning ไปใช้งาน (Deploy)
บนอุปกรณ์ฝังตัว (Embedded Devices) หรืออุปกรณ์ Edge Computing ได้โดยตรง

หัวใจหลักของ Edge Impulse คือการย้ายกระบวนการวิเคราะห์ข้อมูลหรือการตัดสินใจ (Inference) จากเดิมที่ต้องส่งข้อมูลทั้งหมดขึ้นไปประมวลผลบนคลาวด์
ให้ลงมาทำงานได้บนอุปกรณ์ขนาดเล็ก เช่น ไมโครคอนโทรลเลอร์ (MCU) หรือเกตเวย์


----------------------------------------------------------------------

โครงสร้างและวงจรการทำงานของ Edge Impulse (MLOps Workflow)
---------------------------------------------------------

กระบวนการสร้างโมเดลใน Edge Impulse ถูกร้อยเรียงเป็นขั้นตอนที่เรียกว่า **"Impulse"** ซึ่งประกอบด้วย 4 ส่วนสำคัญ:


### 1. Data Acquisition (การรวบรวมข้อมูล)

  - รองรับการเก็บข้อมูลจากเซ็นเซอร์หลากหลายประเภท เช่น ความเร่ง (Vibration/Motion), เสียง (Audio), ภาพ (Vision) หรือข้อมูลตัวเลข Time-series

  - สามารถสตรีมข้อมูลเข้ามาบันทึกได้ผ่านสมาร์ตโฟน, บอร์ดพัฒนา (เช่น ESP32, Arduino) ผ่าน Edge Impulse CLI/Data Forwarder
    หรือนำเข้าชุดข้อมูล (Import Datasets) ผ่าน REST API และเว็บโดยตรง


### 2. Processing Block (การประมวลผลสัญญาณดิจิทัล - DSP)

  - ก่อนนำข้อมูลดิบไปเข้าโครงข่ายประสาทเทียม Edge Impulse จะใช้เทคนิค DSP เพื่อสกัดคุณลักษณะสำคัญ (Feature Extraction) ออกมาก่อน

  - เช่น การใช้ **Spectral Analysis / FFT** สำหรับวิเคราะห์การสั่นสะเทือนของเครื่องจักร,
    การใช้ **MFCC/MFE** สำหรับสัญญาณเสียง, หรือการทำ Normalization/Resize สำหรับภาพ


### 3. Learning Block (การสร้างและเทรนโมเดล)

  - ออกแบบโครงข่ายประสาทเทียมตามงาน เช่น Classification (จำแนกประเภท), Anomaly Detection (ตรวจจับความผิดปกติ), หรือ Object Detection (เช่น โมเดล FOMO)

  - มีระบบ **EON Tuner (AutoML)** ช่วยค้นหาสถาปัตยกรรมโมเดลและพารามิเตอร์ที่แม่นยำที่สุด ภายใต้ข้อจำกัดของฮาร์ดแวร์เป้าหมาย (Latency, RAM, Flash)


### 4. Deployment (การนำไปติดตั้งบนอุปกรณ์)

  - แปลงโมเดลที่ผ่านการเทรนออกมาเป็น **C++ Source Code Library** หรือ **Arduino Library** ที่ไม่มี external dependencies ซับซ้อน

  - โค้ดที่ได้สามารถนำไปรวมเข้ากับเฟิร์มแวร์ C++ (เช่น FreeRTOS, ESP-IDF, Zephyr) เพื่อให้ฮาร์ดแวร์ทำงานได้ด้วยตัวเองแบบออฟไลน์ 100%

จุดเด่นเชิงวิศวกรรมที่ทำให้ Edge Impulse แตกต่าง
---------------------------------------------------

  - **EON Compiler (การประหยัดทรัพยากรระดับสูง):**
    แพลตฟอร์มมีคอมไพเลอร์ที่แปลงโมเดลออกมาเป็น C++ แบบ Pure code โดยไม่ต้องพึ่งพาตัวแปลคำสั่ง (Interpreter Overhead)
    ของ TensorFlow Lite for Microcontrollers (TFLM) ทำให้ลดการใช้ RAM ลงสูงสุดราว 55% และลดพื้นที่ Flash ROM ลงราว 35%

  - **On-Device Inference & Zero Cloud Latency:**
    อุปกรณ์สามารถประมวลผลและตัดสินใจได้ทันทีโดยไม่ต้องต่ออินเทอร์เน็ต ช่วยลดแบนด์วิธในการสื่อสาร ประหยัดพลังงานแบตเตอรี่
    และรักษาความเป็นส่วนตัวของข้อมูล (Privacy)

  - **Open & Extensible:**
    โมเดลและฟังก์ชัน DSP ทั้งหมดสามารถ Export ออกมาเป็น C++ โค้ดแบบเปิด (Open formats) ให้นำไปคอมไพล์ด้วยคอมไพเลอร์ใดๆ ก็ได้
    และสามารถควบคุมวงจร MLOps ทั้งหมดผ่าน Python SDK หรือ Studio REST API
